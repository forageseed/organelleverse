## Security notice

`verify_capability` EXECUTES this bundle's code inside the controlled
worker subprocess BEFORE any trust record exists. Verification imports
and runs the module named by `callable_locator` in order to inspect its
real signature and (for fixture-bearing bundles) evaluate it - so it
already ran the code by the time it returns. Only call
`verify_capability` on a bundle whose code you have read and are
willing to run. `trust(...)` is a separate, later step: trust is
granted only after verification succeeds, never before it.
